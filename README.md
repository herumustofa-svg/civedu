# CIVEDU - Platform Pembelajaran Civic Edupreneurship 🏛️

Platform pembelajaran interaktif berbasis web untuk Civic Edupreneurship. Aplikasi ini dibuat menggunakan HTML/Tailwind CSS dan di-hosting melalui Streamlit.

## 🚀 Cara Menjalankan Secara Lokal

1. **Clone repository (atau download project):**
   ```bash
   git clone <url-repo-anda>
   cd "PROJECT BUNDA"
   ```

2. **Install dependensi:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Jalankan aplikasi Streamlit:**
   ```bash
   streamlit run app.py
   ```

Aplikasi akan otomatis terbuka di browser pada alamat `http://localhost:8501`.

---

## 🌐 Deploy ke Streamlit Community Cloud

1. Push repository ini ke **GitHub**.
2. Kunjungi [Streamlit Community Cloud](https://share.streamlit.io/) dan login dengan akun GitHub Anda.
3. Klik tombol **New app**.
4. Pilih repository ini, branch `main`, dan file utama `app.py`.
5. Klik **Deploy!** 🚀
